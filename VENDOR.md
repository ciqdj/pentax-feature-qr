# QR encoder

`qrcodegen.ts` comes from Project Nayuki's QR Code generator (MIT):

https://github.com/nayuki/QR-Code-generator/blob/bcfe1b018cec5f1f91b5705eca5bb4cdd34e9f8d/typescript-javascript/qrcodegen.ts

The upstream license is preserved at the top of the file. The only local addition is `export { qrcodegen };` at the end, for ES module bundling. The browser distribution includes the complete upstream license in `THIRD-PARTY-NOTICES.txt`.
